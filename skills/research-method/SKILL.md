# Research method
1. Restate the question and what a good answer contains.
2. Search team knowledge first (knowledge_search), then fetch only URLs given in the request or found in knowledge.
3. Prefer primary and reputable sources; note trust scores from tool output.
4. Each claim gets a citation: the URL or [S#]. Mark claims supported by one source only as "single-source".
5. End with: Key findings, Evidence (bulleted, cited), Open questions.
